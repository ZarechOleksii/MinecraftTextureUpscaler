# Code of conduct

This project is for making Minecraft textures look better, and everyone taking part should be able to do that without
being harassed.

## Expected

- Be respectful and patient, especially with people who are new to the tool or to Python.
- Criticise code and ideas, not people.
- Accept that the maintainer decides what goes into the project, and that a "no" is not personal.

## Not acceptable

- Harassment, insults, discrimination or personal attacks of any kind.
- Publishing someone else's private information.
- Spam, or advertising unrelated to the project.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests that break these rules and may ban repeat
offenders. To report a problem, use GitHub's **Report content** link on the comment, or contact the maintainer through
their GitHub profile.

This text is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
