# Sample textures

The PNG files in this folder are textures from the `default` mod of
[Minetest Game](https://github.com/luanti-org/minetest_game/tree/master/mods/default/textures) (now Luanti Game),
downloaded unchanged on 2026-11-04. Each is 16x16 and is named like the original without the `default_` prefix
(for example `brick.png` is `default_brick.png`).

  <https://creativecommons.org/licenses/by-sa/3.0/>.
- **Author:** the Minetest Game contributors. The upstream `license.txt` (kept here as
  `LICENSE-minetest_game.txt`) lists them by license group, not per texture, so this folder credits the group.
- **Adaptations:** the images under `docs/presets/img/` are upscaled versions of these textures, so they are
  adaptations and are also licensed CC BY-SA 3.0. The code of this project is not affected.

To add textures here, add the PNG and an entry to `samples.toml`, and say who made it and under which license in
that entry's `credit` and in this file. Only textures that may be redistributed belong in this folder.
